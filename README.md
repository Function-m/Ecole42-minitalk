## 프로젝트 개요

본 프로젝트는 UNIX 시그널을 사용하여 작은 데이터 교환 프로그램을 구현하는 것을 목표로 합니다. </br>
클라이언트와 서버 두 개의 프로그램으로 구성되며, 클라이언트는 서버의 PID와 문자열을 인자로 받아 서버에 전달하고, 서버는 전달받은 문자열을 출력합니다.

## 구현 내용

### 필수 파트

* 서버는 먼저 실행되며, 실행 후 자신의 PID를 출력합니다.
* 클라이언트는 서버의 PID와 보낼 문자열을 인자로 받습니다.
* 클라이언트는 문자열을 서버에 전송하고, 서버는 이를 출력합니다. [cite: 35, 36]
* 서버는 문자열을 빠르게 출력해야 합니다. [cite: 37, 38, 39]
* 서버는 재시작 없이 여러 클라이언트로부터 문자열을 받을 수 있어야 합니다. [cite: 40]
* 통신은 오직 UNIX 시그널(SIGUSR1, SIGUSR2)을 통해서만 이루어져야 합니다. [cite: 41, 42]

### 보너스 파트

* 서버는 클라이언트로부터 메시지를 받을 때마다 클라이언트에게 시그널을 보내 수신을 알립니다. [cite: 44]
* 유니코드 문자열을 지원합니다. [cite: 45]

**참고:** 보너스 요구사항은 필수 요구사항이 완벽하게 구현되고 정상적으로 동작할 경우에만 평가됩니다. [cite: 45, 46, 47]

## 사용 방법

### 컴파일 방법

Makefile을 사용하여 컴파일합니다.

```bash
make
```

이 명령은 `client` 와 `server` 실행 파일을 생성합니다.  
보너스 기능을 포함하여 컴파일하려면 아래 명령어를 사용하세요.

```bash
make bonus
```

### 실행 방법

1.  먼저 서버를 실행합니다.

    ```bash
    ./server
    ```

    서버는 자신의 PID를 출력합니다.
2.  클라이언트를 실행하여 서버에 문자열을 보냅니다.

    ```bash
    ./client <server_pid> "<string_to_send>"
    ```

    `<server_pid>`는 서버가 출력한 PID로 대체하고, `<string_to_send>`는 보낼 문자열로 대체합니다.

    예시:

    ```bash
    ./client 1234 "Hello, world!"
    ```
